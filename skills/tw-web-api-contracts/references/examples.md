# Reference Implementations

This skill is **repo-agnostic**. Do not assume file paths from any particular solution.
Always discover conventions in the **current repo** first.

## Discover conventions in the current repo

Repos differ in path casing (kebab `features/` vs Pascal `Features/`) — search case-insensitively:

```bash
# Find the contracts project
find . -iname '*contracts*.csproj' -not -path '*/obj/*' -not -path '*/[Tt]ests/*'

# Find existing contracts to mirror
rg -l --ignore-case 'public static partial class' --glob '**/[Ff]eatures/**/*.cs'
rg -l 'ApiRoute' --glob '**/[Ff]eatures/**/*.cs'

# Find the contracts test project
find . -ipath '*contracts?tests*' -name '*.csproj' -not -path '*/obj/*'

# Find mock service registration (two patterns exist — contract-local factory vs *MockFactory classes)
rg -l 'GetMockResponseFactory|MockFactory|Mock.*ApiService' --glob '**/*.cs'
```

Read 2–3 files from the same feature area before scaffolding a new contract.

## Tier 1 — Simple query (route-only)

Empty `Query` body is valid **here only**: no data interface, so `[ApiRoute]`'s generated members
are all the class needs. Empty validator is valid.

```csharp
namespace MyApp.Features.Announcements;

public static partial class GetAnnouncementsForCurrentUser
{
  [ApiRoute("api/Users/Current/Announcements", HttpVerb.Get)]
  public sealed partial class Query : IApiRequest, IRequest<OneOf<Response, SharedProblemDetails>>;

  public sealed class Validator : AbstractValidator<Query>;

  public sealed class Response : ListResponse<AnnouncementDto>
  {
    public Response(int totalCount, AnnouncementDto[] items) : base(totalCount, items) { }
  }

  public sealed class AnnouncementDto
  {
    public string? Text { get; init; }
    public string? Link { get; init; }
  }

  public static MockResponseFactory<Response> GetMockResponseFactory()
  {
    AnnouncementDto[] items = [new() { Text = "Sample", Link = "/home" }];
    return _ => new Response(totalCount: items.Length, items);
  }
}
```

## Tier 2 — CRUD with bindable interface

Folder `features/admin/security-roles/` (plural; kebab canonical — match `Features/Admin/SecurityRoles/`
if the repo uses PascalCase) · namespace `MyApp.Features.Admin.SecurityRoles`.

**Shared shape + validator** (`security-role-details.cs`). Interface properties have **no
initializers** (C# forbids them on interfaces) — `= null!` belongs on implementing classes:

```csharp
namespace MyApp.Features.Admin.SecurityRoles;

public interface ISecurityRoleDetails
{
  public string Name { get; set; }
  public string? Description { get; set; }
  public string Code { get; set; }
}

public sealed class SecurityRoleDetailsValidator : AbstractValidator<ISecurityRoleDetails>
{
  public SecurityRoleDetailsValidator()
  {
    RuleFor(x => x.Name).NotEmpty().MaximumLength(255);
    RuleFor(x => x.Description).MaximumLength(255).When(x => x.Description != null);
    RuleFor(x => x.Code).NotEmpty().MaximumLength(50);
  }
}
```

**Create command** — implements the interface and **declares its properties** (an empty body will
not compile: interface members are not source-generated); composes the shared validator:

```csharp
public static partial class CreateSecurityRole
{
  [ApiRoute("api/SecurityRoles", HttpVerb.Post)]
  public sealed partial class Command
    : IApiRequest, ISecurityRoleDetails, IRequest<OneOf<Response, SharedProblemDetails>>
  {
    public string Name { get; set; } = null!;
    public string? Description { get; set; }
    public string Code { get; set; } = null!;
  }

  public sealed class Validator : AbstractValidator<Command>
  {
    public Validator() => RuleFor(x => x).SetValidator(new SecurityRoleDetailsValidator());
  }

  // Response has an invariant (a real id), so ctor + Guard — `required init` would let
  // an unset/zero id ship silently.
  public sealed class Response
  {
    public int SecurityRoleId { get; }
    public Response(int securityRoleId) =>
      SecurityRoleId = Guard.Against.NegativeOrZero(securityRoleId);
  }
}
```

**Get for edit** — Response implements the same interface (route param `SecurityRoleId` is
generated by `[ApiRoute]`; the `Query` body stays empty because it has no data interface):

```csharp
public static partial class GetSecurityRole
{
  [ApiRoute("api/SecurityRoles/{SecurityRoleId:min(1)}", HttpVerb.Get)]
  public sealed partial class Query : IApiRequest, IRequest<OneOf<Response, SharedProblemDetails>>;

  public sealed class Validator : AbstractValidator<Query>;

  public sealed class Response : ISecurityRoleDetails
  {
    public int SecurityRoleId { get; }
    public string Name { get; set; }
    public string? Description { get; set; }
    public string Code { get; set; }

    public Response(int securityRoleId, string name, string code, string? description = null)
    {
      SecurityRoleId = Guard.Against.NegativeOrZero(securityRoleId);
      Name = Guard.Against.NullOrWhiteSpace(name);
      Code = Guard.Against.NullOrWhiteSpace(code);
      Description = description;
    }
  }
}
```

**Blazor side (library-dependent):** bind `EditForm` to the interface and pass the shared
validator **explicitly** — Blazilla supports an explicit instance; runtime-type resolvers
(Morris) cannot find `AbstractValidator<ISecurityRoleDetails>` for a `Command` model:

```razor
<EditForm Model=@Details OnValidSubmit=HandleValidSubmit>
  <FluentValidator Validator="@(new SecurityRoleDetailsValidator())" />
  ...
</EditForm>

@code {
  private ISecurityRoleDetails Details = default!; // = CreateSecurityRole.Command instance
}
```

## Tier 3 — Filterable list + query string

Optional nullable filters; no unconditional required rules on filters. With
`[AuthApiRequest]`/`[OpenDataQueryParameters]`, compose the generated helpers:

```csharp
public static partial class GetAccountOwnedPolicies
{
  [ApiRoute("api/Accounts/{AccountId:int}/Policies/Owned", HttpVerb.Get)]
  public sealed partial class Query : IQueryStringRouteProvider, IRequest<OneOf<Response, SharedProblemDetails>>
  {
    public string? State { get; set; }

    public string GetRouteWithQueryString()
    {
      var parameters = new NameValueCollection { { nameof(State), State } };
      return $"{GetRoute()}?{this.GetQueryString(parameters)}";
    }
  }

  public sealed class Validator : AbstractValidator<Query>
  {
    public Validator()
    {
      RuleFor(x => x.State).Length(2).When(x => x.State != null);
    }
  }
}
```

For an authenticated, pageable list see `get-roles.cs` in the timewarp-architecture template — it
stacks `[ApiRoute]` + `[OpenDataQueryParameters]` + `[AuthApiRequest]` and composes
`GetAuthQueryParameters()` + `GetOpenDataQueryParameters()` into the query string.

## Tier 4 — Contract test (serialization)

Host-free round-trip in the dedicated contracts test project (Fixie + Shouldly):

```csharp
public class Command_Should_
{
  public static void SerializeAndDeserialize()
  {
    JsonSerializerOptions options = new() { PropertyNamingPolicy = JsonNamingPolicy.CamelCase };

    CreateSecurityRole.Command command = new() { Name = "Admin", Code = "ADMIN" };
    string json = JsonSerializer.Serialize(command, options);
    CreateSecurityRole.Command? parsed = JsonSerializer.Deserialize<CreateSecurityRole.Command>(json, options);

    parsed.ShouldNotBeNull();
    parsed.Name.ShouldBe(command.Name);
    parsed.Code.ShouldBe(command.Code);
    parsed.Description.ShouldBe(command.Description);
  }
}
```

## Folder and namespace (both plural)

| Folder | Namespace |
|--------|-----------|
| `features/admin/security-roles/` (kebab repos) | `MyApp.Features.Admin.SecurityRoles` |
| `Features/Incidents/` (Pascal repos) | `MyApp.Features.Incidents` |

Plural throughout — the folder and namespace agree; plural namespaces also avoid collisions with
`SecurityRole`, `User`, `Policy` class names.

## Existing-code caution

Existing solutions may contain shapes that contradict this spec — `string?` + unconditional
`NotEmpty()`, standalone `*MockFactory` classes in the SPA, singular feature folders. **Mirror a
repo's naming and layout conventions, but do not copy rule violations into new contracts** — apply
[nullability.md](nullability.md) and this skill's rules.
