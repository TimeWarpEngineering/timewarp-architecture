# Option 2C, minimal: domain declares the root, generator fills it from the contracts

Persistence (tables, columns, EF) is deliberately left out of this document.

---

## 1. Input: the contracts (real, in `web-contracts`, unchanged)

```csharp
// role-details-contracts.cs
public interface IRoleDetails
{
  public string Name { get; set; }
  public string Description { get; set; }
}

public sealed class RoleDetailsValidator : AbstractValidator<IRoleDetails>
{
  public RoleDetailsValidator()
  {
    RuleFor(r => r.Name).NotEmpty();
    RuleFor(r => r.Description).NotEmpty();
  }
}

// create-role-contracts.cs
[Operation("roles.create", Group = "admin.roles")]
public sealed partial class Command : IRoleDetails, ICommand<...> { public string Name { get; set; } public string Description { get; set; } }

// update-role-contracts.cs
[ApiRoute("api/Roles/{RoleId:guid}", HttpVerb.Put)]
[Operation("roles.update", Group = "admin.roles")]
public sealed partial class Command : IRoleDetails, ICommand<...> { public string Name { get; set; } public string Description { get; set; } }

// set-role-permissions-contracts.cs
[ApiRoute("api/Roles/{RoleId:guid}/permissions", HttpVerb.Put)]
[Operation("roles.set-permissions", Group = "admin.roles")]
public sealed partial class Command : IIdempotentCommand<...> { public List<string> PermissionIds { get; set; } = []; }

// set-role-agent-scopes-contracts.cs
[ApiRoute("api/Roles/{RoleId:guid}/agent-scopes", HttpVerb.Put)]
[Operation("roles.set-agent-scopes", Group = "admin.roles")]
public sealed partial class Command : IIdempotentCommand<...> { public List<string> Scopes { get; set; } = []; }

// delete-role, get-role, get-roles: [Operation("roles.delete" | "roles.get" | "roles.list", Group = "admin.roles")]
```

## 2. What a person writes (in `web-domain`)

```csharp
// role-id-domain.cs
[TypedId]
public readonly partial record struct RoleId;
```

```csharp
// role-domain.cs
[Aggregate(OperationGroup = "admin.roles")]
public sealed partial class Role : Entity<RoleId>, IAggregateRoot
{
  private partial void ConfigureInvariants(Invariants rules)
  {
    rules.RuleForEach(role => role.Permissions).Must(static p => RoleCatalogs.PermissionIds.Contains(p.Value));
    rules.RuleForEach(role => role.AgentScopes).Must(static s => RoleCatalogs.AgentScopes.Contains(s.Value));
  }
}
```

That is all. The class says "I am the aggregate root for the `admin.roles` operations" and writes
the two rules the contracts cannot express (they call catalogs the domain copies in).

## 3. What the generator emits (in `web-domain`, `Role.g.cs`)

How each piece was derived is in the comment above it.

```csharp
// <auto-generated/>
public sealed partial class Role
{
  // IRoleDetails: implemented by the create and update commands of group admin.roles.
  public string Name { get; private set; }
  public string Description { get; private set; }

  // roles.set-permissions: its command has one list member (PermissionIds). Child name is the
  // operation verb's object, kebab to Pascal: set-permissions -> Permissions.
  private readonly List<RolePermission> PermissionList = [];
  public IReadOnlyList<RolePermission> Permissions => PermissionList;

  // roles.set-agent-scopes: one list member (Scopes). set-agent-scopes -> AgentScopes.
  private readonly List<RoleAgentScope> AgentScopeList = [];
  public IReadOnlyList<RoleAgentScope> AgentScopes => AgentScopeList;

  private Role(RoleId id, string name, string description)
    : base(id)
  {
    Name = name;
    Description = description;
  }

  // roles.create: parameters are the IRoleDetails members.
  public static Role Create(string name, string description)
  {
    ArgumentException.ThrowIfNullOrWhiteSpace(name);
    ArgumentException.ThrowIfNullOrWhiteSpace(description);
    return new Role(RoleId.New(), name, description);
  }

  public static Role Create(RoleId id, string name, string description)
  {
    if (id.IsEmpty)
    {
      throw new ArgumentException("RoleId must be non-empty.", nameof(id));
    }

    ArgumentException.ThrowIfNullOrWhiteSpace(name);
    ArgumentException.ThrowIfNullOrWhiteSpace(description);
    return new Role(id, name, description);
  }

  // roles.update: the command implements IRoleDetails, so it replaces the details as a set.
  public void UpdateDetails(string name, string description)
  {
    ArgumentException.ThrowIfNullOrWhiteSpace(name);
    ArgumentException.ThrowIfNullOrWhiteSpace(description);
    Name = name;
    Description = description;
  }

  // roles.set-permissions: IIdempotentCommand, so full replace.
  public void SetPermissions(IReadOnlyCollection<string> permissionIds)
  {
    ArgumentNullException.ThrowIfNull(permissionIds);
    PermissionList.Clear();
    PermissionList.AddRange(permissionIds.Distinct(StringComparer.Ordinal).Select(RolePermission.Create));
  }

  // roles.set-agent-scopes: IIdempotentCommand, so full replace.
  public void SetAgentScopes(IReadOnlyCollection<string> scopes)
  {
    ArgumentNullException.ThrowIfNull(scopes);
    AgentScopeList.Clear();
    AgentScopeList.AddRange(scopes.Distinct(StringComparer.Ordinal).Select(RoleAgentScope.Create));
  }

  // roles.delete, roles.get, roles.list: store operations, nothing on the entity.

  // Required hook. No body here, so the build fails (CS8795) until role-domain.cs supplies one.
  private partial void ConfigureInvariants(Invariants rules);

  private sealed class Invariants : AbstractValidator<Role>
  {
    public Invariants()
    {
      // RoleDetailsValidator, read from role-details-contracts.cs
      RuleFor(role => role.Name).NotEmpty();
      RuleFor(role => role.Description).NotEmpty();

      // The Must(...) rules in the set-* validators call catalogs the domain cannot see,
      // so they come from the hand-written hook.
      ConfigureInvariants(this);
    }
  }
}

// One value record per child. Max length is a persistence fact and is not decided here.
public sealed record RolePermission
{
  private RolePermission(string value) => Value = value;
  public string Value { get; }

  public static RolePermission Create(string value)
  {
    ArgumentException.ThrowIfNullOrWhiteSpace(value);
    return new RolePermission(value);
  }
}

public sealed record RoleAgentScope
{
  private RoleAgentScope(string value) => Value = value;
  public string Value { get; }

  public static RoleAgentScope Create(string value)
  {
    ArgumentException.ThrowIfNullOrWhiteSpace(value);
    return new RoleAgentScope(value);
  }
}
```

(`ConfigureInvariants(this)` from inside the nested class needs either a static hook or an
owner reference; that is a generator detail and does not change what the person writes.)

## 4. What the build check reports (analyzer in `web-application`, which sees both assemblies)

```text
error    Role declares [Aggregate(OperationGroup = "admin.roles")] but no contract in web-contracts has that group.
error    Group admin.roles has create and update commands that do not implement one shared details interface.
warning  Operation roles.set-tags in group admin.roles has no matching member on Role (expected a one-list command, or mark the operation [NotAggregate]).
```

Renaming `IRoleDetails.Description` to `Summary` does not need a diagnostic: the generated
`Role.Summary` replaces `Role.Description`, and every hand-written caller of `Description`
fails to compile. The golden diff gate shows the rename too.

## 5. The rules the generator follows, in one list

1. The class with `[Aggregate(OperationGroup = G)]` is the root. One root per group.
2. The details interface is the interface that both the `create` and `update` commands of G implement. Its members become `{ get; private set; }` properties, `Create` parameters, and `UpdateDetails` parameters.
3. The details validator's rules (`NotEmpty`, `MaximumLength`, `NotNull`) become `Invariants` rules on the same members.
4. Each `set-<name>` operation whose command has exactly one `List<T>` member becomes a child collection `<Name>` of value records, with `Set<Name>` as a full replace when the command is idempotent.
5. Any `Must(...)` rule in a contract validator is not copied; it is the hook's responsibility.
6. `delete`, `get`, `list` produce nothing on the entity.
7. Anything in G that matches none of the above is a warning until a person adds a member or marks it `[NotAggregate]`.
